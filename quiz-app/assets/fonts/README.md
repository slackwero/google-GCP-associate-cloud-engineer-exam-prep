# Roboto

`roboto-latin.woff2` y `roboto-latin-ext.woff2` son subconjuntos (latin y
latin-ext) de **Roboto**, la familia tipográfica de Google.

- **Autor:** Google Fonts
- **Licencia:** Apache License 2.0 — https://www.apache.org/licenses/LICENSE-2.0
- **Origen:** https://fonts.google.com/specimen/Roboto

La Apache License 2.0 permite redistribuir estos archivos dentro de este
repositorio. Se alojan localmente en vez de enlazar a `fonts.googleapis.com`
para que la aplicación funcione sin conexión, ya que estudiar sin internet es
un escenario de uso real.

Solo se incluyen los subconjuntos latin y latin-ext porque la interfaz y el
banco de preguntas están en inglés y español.
